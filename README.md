# Indie Hackers City

Indie Hackers City is a web experience shaped by the progress of independent
builders. This repository currently contains the production-ready application
foundation; product features will be introduced in later stages.

## Requirements

- Node.js 20.9 or newer (Node.js 22 recommended)
- npm

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

## Quality checks

Run the linter:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```

Run the production server after building:

```bash
npm run start
```

Authentication, data storage, milestone verification, the admin workflow, and
the interactive 2D city are intentionally deferred to future stages.
